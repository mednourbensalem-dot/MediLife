# MediLife

**Your Health, Organized. Your Care, Connected.**

MediLife is an online healthcare management platform designed to organize patients' medical records, doctor appointments, medical documents, and healthcare activities in one place.

## Features

- Digital medical dossiers
- Patient and doctor management
- Appointment scheduling and calendar
- Medical document organization
- Medication and follow-up reminders
- Administrative dashboard

## Technologies

- HTML
- CSS
- JavaScript
